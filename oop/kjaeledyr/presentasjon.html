Tungvint 1: global overalt


def leke():
    global sult, energi, glede
    glede = begrens(glede + 3)
    energi = begrens(energi - 2)
    sult = begrens(sult + 1)

Glemmer du én variabel i global-linja → UnboundLocalError.

Og hvem som helst, hvor som helst, kan endre sult.

Tungvint 2: Kopiert kode


def mate(hvilket):
    global sult1, glede1, sult2, glede2
    if hvilket == "1":
        sult1 = begrens(sult1 - 3)
        glede1 = begrens(glede1 + 1)
    else:
        sult2 = begrens(sult2 - 3)
        glede2 = begrens(glede2 + 1)

Samme logikk to ganger. Og for 10 dyr? 😱

Finner du en feil i regelen, må du rette den på alle stedene.

Tungvint 3: Lange parameterlister

Steg 1–2: Klassen og objektene


class Kjaeledyr:
    def __init__(self, navn):
        self.navn = navn
        self.sult = 5
        self.energi = 5
        self.glede = 5


fido = Kjaeledyr("Fido")
pusur = Kjaeledyr("Pusur")

print(fido.sult)   # i stedet for dyr["sult"] eller sult1
__init__ kjøres automatisk når vi skriver Kjaeledyr("Fido"). self er dyret som blir laget. Vis i VS Code: skriv fido. og se forslagene. Skriv fido.slut og se at den blir markert.

Steg 3–4: Metoder


    def mate(self):
        self.sult = begrens(self.sult - 3)
        self.glede = begrens(self.glede + 1)
        print(f"Du ga {self.navn} mat.")


fido.mate()

Ingen global. Ingen if hvilket == "1". Ingen lange parameterlister.

Hva er egentlig self?


fido.mate()

... betyr egentlig:


Kjaeledyr.mate(fido)

Python sender automatisk objektet foran punktumet inn som self.

Når pusur.mate() kjøres, er self Pusur.

Steg 5: En liste med objekter


dyrene = [Kjaeledyr("Fido"), Kjaeledyr("Pusur"), Kjaeledyr("Rex")]

for dyr in dyrene:
    dyr.tiden_gaar()

Fungerer for 3 dyr — eller 300.

Adoptere nytt dyr: dyrene.append(Kjaeledyr("Bamse"))

Diskuter to og to

Typiske svar: 1) Overalt — lang og lite lesbar kode. 2) KeyError først når akkurat den linjen kjøres. VS Code kan ikke hjelpe, det er bare tekst. 3) Nesten alle — og de trenger kontonummer i tillegg. 4) Historikk: opprett_kunde, sett_inn, ta_ut, ny funksjon, meny, startdata/JSON. Gamle kunder gir KeyError. 5) vis_saldo, ta_ut (to ganger), opprett_kunde, legg_til_renter. Ny type = lete opp alle. 6) Ingen steder — "det kommer an på typen". Må lese opprett_kunde eller JSON-fila. 7) Ingenting. Ærlig: Python-klasser hindrer det ikke helt heller, men vi kan signalisere det (steg 2).

Steg 2: Metoder

Vi flytter funksjonene inn i klassen.


class Konto:
    def __init__(self, kontonummer, navn, saldo=0):
        self.kontonummer = kontonummer
        self.navn = navn
        self._saldo = saldo

    def sett_inn(self, belop):
        if belop <= 0:
            print("Beløpet må være større enn 0.")
            return
        self._saldo += belop
        print(f"Satte inn {belop} kr.")

ola = Konto("1001", "Ola Nordmann", 1500)
ola.sett_inn(500)

Steg 3: Mange kontoer

Konto = én konto. Men hvem holder styr på alle?


class Bank:
    def __init__(self):
        self.kontoer = {}  # kontonummer -> Konto-objekt

    def legg_til(self, konto):
        self.kontoer[konto.kontonummer] = konto

    def finn_konto(self, kontonummer):
        if kontonummer not in self.kontoer:
            return None
        return self.kontoer[kontonummer]

Steg 4: Sparekonto med arv

En sparekonto er en konto — med noen ekstra regler.


class Sparekonto(Konto):  # arver alt fra Konto
    MAKS_UTTAK = 3

    def __init__(self, kontonummer, navn, saldo=0):
        super().__init__(kontonummer, navn, saldo)
        self.uttak = 0

    def ta_ut(self, belop):
        if self.uttak >= self.MAKS_UTTAK:
            print("Du har brukt opp uttakene.")
            return False
        if super().ta_ut(belop):
            self.uttak += 1
            return True
        return False

📄 steg4_sparekonto.py

Arv: Sparekonto får alt fra Konto. Overstyring: egen ta_ut() brukes i stedet. super(): kaller metoden i Konto, så vi slipper å skrive reglene på nytt. Alt som er spesielt for sparekontoen står HER — ikke spredt rundt i koden.
